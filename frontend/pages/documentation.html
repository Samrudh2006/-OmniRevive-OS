Developer Documentation & Quickstart

Version: 1.1.0 Framework: FastAPI + Vanilla SRE Frontend Author: Samrudh Dwivedula

1. Quickstart Installation

# Clone the repository
git clone https://github.com/Samrudh2006/-OmniRevive-OS.git
cd -OmniRevive-OS

# Install dependencies
pip install -r requirements.txt

# Run server locally
python -m uvicorn backend.app.main:app --port 8000 --reload

2. Key REST API Endpoints

  • POST /api/v1/recovery/simulate-failure: Ingest a simulated payment drop and trigger the autonomous Fast-Loop recovery pipeline.
  • POST /api/v1/recovery/dynamic-upi-qr: Generate an instant dynamic UPI intent link and payment QR for soft decline recovery.
  • POST /api/v1/recovery/batch: Bulk recovery orchestrator for processing CSV and JSON failure batches with thread concurrency.
  • GET /api/v1/audit/verify: Verify the integrity of the sequential SHA-256 Merkle audit chain from genesis to leaf.
  • POST /api/v1/b2b/dispute: Ingest a B2B invoice dispute and initiate trilingual voice negotiation FSM.
  • GET /api/v1/system/health: Prometheus SRE metrics, live rail status, and health telemetry.

3. Interactive CLI Commands

# Check health and rail telemetry
python cli.py health

# Run the 100-case held-out benchmark
python cli.py benchmark

# Verify cryptographic audit ledger
python cli.py verify-audit

# Launch conversational recovery copilot
python cli.py chat

4. Enterprise Cloud Deployment

OmniRevive-OS includes ready configurations for:

  • Antideploy: Procfile, runtime.txt, and .dockerignore (Live at https://omnirevive-os.antideploy.com/).
  • Cloudflare Workers & Pages: Edge WAF, Turnstile bot defense, R2 audit receipts, and wrangler.toml.
  • Docker: Production multi-stage Dockerfile with non-root security container.
