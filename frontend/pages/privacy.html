Privacy Policy

Effective Date: October 9, 2026 · Version 1.2.0-Production

1. Executive Overview

OmniRevive-OS is an open-source project (github.com/Samrudh2006/-OmniRevive-OS). The hosted site is a demonstration that runs on simulated data. It has not been audited or certified against DPDP 2023, RBI data localization directives or GDPR, and it should not be given real customer or card data.

2. Vector Memory

Past failure cases are compared by semantic similarity using a Qdrant vector store that the demo runs in memory, with a NumPy fallback. The demo data is synthetic. Review the source code before sending any real personal data through it.

3. Hosting

The demo is hosted on third-party platforms (Render and Antideploy) that choose their own data centre locations. We make no claim about where it runs. The repository includes an AWS Mumbai and Hyderabad edge-routing simulation, which is part of the demo and not a statement about the live hosting.

4. Voice Demo

The Deep-Loop voice demo (Telugu, Hindi and English) uses scripted scenarios. If you run it yourself with real voice or telephony providers, their own retention terms apply.

5. Audit Ledger

Audit events in the demo are hashed into a SHA-256 Merkle tree (RFC 6962 style) so inclusion proofs can be checked. The proof module is in backend/app/merkle_proof.py.
